## How to Run the Code

### Option 1: Running on DartPad (Recommended)
1. Open your browser and go to [DartPad](https://dartpad.dev).
2. Copy the entire code from `main.dart` in this repository.
3. Paste the code into the DartPad editor.
4. Click the **Run** button at the top to view the simulated async outputs in the console.
